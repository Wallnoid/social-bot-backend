# General project rules

- Make minimal changes focused on what was asked; don't refactor unrelated code.
- Follow the conventions already present in the code before introducing new ones.
- New logic must come with tests, or an explicit note explaining why not.
- Respect the rules in `docs/business-rules.md`; if a request contradicts them, say so.
- Never put secrets in code or commits; use environment variables.
- If context is missing to decide, ask instead of assuming.
